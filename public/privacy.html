처리하는 정보·목적외부 AI 처리보관 기간브라우저·복구코드삭제와 문의사업자·연락처

1. 처리하는 정보와 목적

  • 지원 문항·초안·지원 정보·추가 확인 답변: 문항 맞춤 첨삭, 원문 대조 검수 및 오류 재시도에 사용합니다.
  • 수정한 결과·변경 전후 발췌·검수 정보: 부분 미리보기, 결제한 전문과 변경 이유 제공 및 전달 중 장애 대응에 사용합니다. 입력 원문을 별도 원문 문서로 보관하지는 않지만, 수정본·발췌·검수 근거에 원문과 동일한 내용이 포함되어 암호화 임시 보관될 수 있습니다.
  • 익명 브라우저 식별·이용량·보안 정보: 첫 무료 미리보기 한도, 결과 소유권, 요청 중복·남용 방지에 사용합니다. 계정이나 개인별 실명 인증을 의미하지 않습니다.
  • 주문·결제·계약 확인 정보: 승인 검증, 결과 제공, 중복 결제 방지, 취소·환불 및 최소 거래기록 보관에 사용합니다.

결제창에 입력한 카드 정보는 결제사업자가 처리합니다. 인소서 화면에서 카드번호·CVC를 직접 입력받거나 브라우저 저장소에 저장하지 않습니다.

2. 외부 AI 처리와 별도 보유 조건

첨삭·추가 확인·별도 검수 요청 시, 이용자의 동의를 받은 초안·지원 문항·추가 답변·지원 정보와 요청 내용을 서비스 서버 및 연결된 외부 AI 처리업체로 전송합니다. AI 요청 전에 처리 안내와 전송 동의를 확인할 수 있습니다.

중계 제공업체가 있는 경우 해당 업체와 실제 모델 처리업체가 관여할 수 있습니다. 업체의 자체 보유 기간, 재이용 여부, 서버 위치와 국외 처리 조건은 해당 업체의 정책·계약 조건을 따르며 아래 인소서의 15분·1시간·24시간 정책과 동일하지 않습니다.

위 연결 정보만으로 제공업체의 상세 처리 조건 전체가 확인되는 것은 아닙니다. 구체적인 조건을 확인하기 전에는 민감한 정보를 보내지 마세요. 인소서의 내용 삭제가 외부 업체의 정책을 바꾸거나 모든 시스템에서 즉시 완전 삭제됨을 보장하지 않습니다.

3. 보관 기간과 분리 보관

  • 재시도 캐시부분 미리보기·추가 확인 질문 등 재시도용 응답은 암호화해 최대 15분 보관하며, 삭제 요청 시 함께 정리합니다. 입력 원문 전체를 재시도 캐시에 넣지 않습니다.
  • 미결제 수정 결과수정문·변경 전후 발췌·검수 근거를 암호화해 생성 시점부터 최대 1시간 임시 보관합니다.
  • 결제 확인 중 / 아직 전달되지 않은 승인 결과결제 확인 시작부터 최대 24시간, 승인 결과는 승인 시각부터 최대 24시간 보호 보관합니다. 다시 열어도 이 기한이 연장되지는 않습니다. 보관 자체가 전문 열람 권한을 뜻하지 않습니다.
  • 전문 전달 후전문이 화면에 전달되면 서비스 DB의 임시 콘텐츠와 재시도 캐시 삭제를 요청합니다. 서버가 성공을 확인해야 삭제 완료로 표시합니다. 실패 시 미완료 안내·재시도 버튼이 표시되며 위 최대 기한이 적용됩니다. 전달 후 현재 화면에서는 복사·저장이 가능하지만, 새로고침·닫기 후 복구할 수 없습니다.
  • 결제·계약 기록주문 식별정보·금액·상태 등 최소 거래기록은 콘텐츠와 분리해 거래일로부터 5년(달력 기준) 보관합니다. 자기소개서 내용을 5년 보관한다는 뜻이 아닙니다. 미승인·미착수 주문은 별도 단기 기한을 적용합니다.

기존 v3 작성 상품으로 생성된 결과에는 기존 고지 기간(미결제 24시간, 승인 확인 대기 최대 7일, 승인일부터 7일)이 적용됩니다. 새 첨삭 상품의 삭제 정책을 기존 결과에 소급 적용하지 않습니다.

작성 중 답변은 현재 페이지의 브라우저 메모리에 유지됩니다. 페이지를 닫거나 새로고침하면 그 입력은 사라질 수 있습니다. 아직 전달되지 않은 결과만 위 기한 안에 소유권·결제 상태를 확인해 받을 수 있습니다. 전달 후 삭제된 결과는 다시 열 수 없습니다.

결과 콘텐츠는 암호화 보관하고, 기한이 지나거나 삭제 요청이 처리되면 서비스 DB의 결과 콘텐츠를 만료·삭제합니다. 응답 전달 중 일시적 메모리와 인프라 백업·로그, 외부 AI의 처리 범위는 이 DB 삭제와 구분됩니다. 앱은 본문을 오류 로그에 의도적으로 남기지 않으며, 인프라 운영·법적 보관의 상세 조건은 운영 전 확인 대상입니다. 모든 시스템에서 즉시 완전 삭제됨을 보장하지 않습니다. 무료 이용 한도·보안·익명 이용량 기록과 결제·계약 기록은 콘텐츠 삭제와 목적이 다른 별도 기록입니다. 내용 삭제만으로 무료 한도가 초기화되지는 않습니다.

4. 쿠키·브라우저 저장소·복구코드

익명 브라우저 쿠키로 동일 브라우저의 이용·결과 접근을 확인합니다. 첫 무료 미리보기는 이 브라우저 기준이며 개인당 1회 인증이 아닙니다. 쿠키 삭제·다른 기기나 브라우저 이용 시 자동으로 같은 소유자로 확인되지 않을 수 있습니다.

작성 중 초안·추가 답변·수정 전문은 현재 페이지 메모리에서만 다루며 localStorage나 sessionStorage에 저장하지 않습니다. 결과 소유권은 익명 쿠키와 서버 기록으로 확인합니다. 새로고침하거나 페이지를 닫으면 입력 및 이미 전달된 수정본은 사라질 수 있습니다.

신규 첨삭 상품은 전문 전달 후 삭제형이며 복구코드를 제공하지 않습니다. 수정본을 확인한 화면에서 직접 복사하거나 TXT로 저장한 뒤 페이지를 닫아주세요. 이용자가 내려받은 파일·클립보드·화면 캡처는 서버 삭제로 회수되지 않습니다.

5. 삭제·정정·문의

초안과 추가 확인 답변은 전송 전 직접 고칠 수 있습니다. 직접 편집한 문장에는 기존 AI 검수가 새로 적용되지 않습니다. AI 검수는 입력 근거와의 대조이지 사실의 진실성 인증이 아닙니다.

서비스의 ‘내용 삭제’는 현재 브라우저의 입력을 비우고, 서버 결과 및 복구권한 삭제를 요청합니다. 서버 처리가 확인되지 않으면 재시도 안내가 표시됩니다. 삭제는 되돌릴 수 없으며 환불 신청이나 무료 한도 초기화가 아닙니다.

정보 확인·정정·삭제 또는 처리 관련 문의는 아래 서버가 제공한 연락처를 이용해주세요. 요청 처리에는 해당 결과 이용 권한 확인이 필요할 수 있습니다. 문의처가 아직 준비되지 않았다면 실결제 준비 중인 상태이며, 임의의 연락처로 개인정보를 보내지 마세요.
