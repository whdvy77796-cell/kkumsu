무료는 개인당 1회 인증 제도가 아닙니다. 첨삭을 요청하기 전과 결제 전에 조건을 확인할 수 있습니다.

서비스와 상품 범위원본 권리·AI 한계결제와 제공청약철회·환불·오류보관과 삭제사업자·문의

1. 서비스와 상품 범위

인소서는 이용자가 붙여넣거나 파일에서 불러온 자소서 1편을 분석·재작성하고 원문 대조 검수를 수행하는 작성 보조 서비스입니다. 1편은 한 번 입력한 40~6,000자의 글입니다. 신규 화면은 문항·직무·회사·공고·글자 수 상한을 별도로 묻지 않으며, 문항 적합성과 분량 상한 준수 여부를 확인한 것처럼 표시하지 않습니다. 자소서에 명시된 정보만 활용하고 부족한 사실을 임의로 만들지 않습니다. 여러 문항을 한꺼번에 입력할 경우 문항별 개별 검수를 보장하지 않습니다. 이전 화면에서 제공한 선택 입력과 추가 확인은 해당 이전 결과에 기존 조건을 적용합니다. 대학 신입학용은 대상에서 제외하지만 대학 경험을 취업용 글에 쓸 수 있습니다.

첫 익명 브라우저 생성 1건은 안전하게 공개 가능한 경우 개선 진단 일부와 수정 전후 발췌 또는 수정본 일부를 무료로 공개합니다. 수정 내역이 없으면 전후 발췌가 없을 수 있습니다. 잠긴 나머지 전문은 미결제 브라우저로 전달하지 않습니다. 미리보기에서는 전문 편집·복사·저장을 제공하지 않으며, 공개된 문장의 캡처·필사까지 막을 수는 없습니다.

3,000원 결제는 이미 첨삭된 해당 자소서 1편 결과의 전문을 여는 상품입니다. 다른 결과, 새 글 생성, 재작성·재검수, 무제한 이용을 포함하지 않습니다. 구독이나 다음 달 자동 청구도 없습니다.

계정을 만들지 않습니다. 익명 브라우저의 이용·소유권 확인으로 결과에 접근하며, 쿠키 삭제나 다른 브라우저 사용까지 통합하는 개인별 1회 인증은 아닙니다. 내용 삭제는 첫 무료 미리보기 한도를 초기화하지 않습니다.

2. 원본 권리와 AI의 한계

입력한 본인의 원본 콘텐츠에 대해 원래 보유한 권리는 서비스 이용만으로 인소서에 이전되지 않습니다. 본인이 이용할 권한이 있는 자료만 입력하고, 다른 사람의 개인정보·영업비밀·저작물을 허락 없이 제공하지 마세요.

AI는 사실·의도·공고 요구를 잘못 해석하거나 비슷한 표현을 만들 수 있습니다. 결과의 정확성, 무오류, 독창성·문장 유일성, 타인 권리 비침해, 독점적인 저작권 성립이나 합격·채용을 보장하지 않습니다.

이용자가 입력 원문의 역할·수치·성과를 확인하고 수정할 수 있습니다. AI는 없는 성과를 만들지 않도록 지시·검수하지만 모든 의미상 왜곡을 기술적으로 보장할 수는 없습니다. 제출 전에는 결과 전체와 지원기관의 AI 활용·블라인드·글자 수 규정을 직접 확인해주세요. 검수는 제출 준비도 점검이며 합격 확률 평가가 아닙니다.

3. 결제와 디지털 콘텐츠 제공

결제창을 열기 전에 금액 3,000원(KRW), 이용 조건, 즉시 제공 동의를 확인받습니다. 실제 결제 준비가 되지 않은 상태에서는 결제를 받지 않으며, 테스트 환경은 실제 구매·청구가 아님을 별도로 표시합니다.

결제사업자의 승인과 서버의 이용 권한 확인이 완료되면 해당 결과의 전문을 즉시 제공합니다. 결제 성공 화면에 도착했다는 사실만으로 전문이 열리지는 않습니다.

확인이 지연되면 다시 결제하지 말고 ‘같은 결제 승인 다시 확인’ 또는 ‘이전 결과 불러오기’를 이용해주세요. 신규 첨삭 전문은 전달 후 삭제형이므로 다른 브라우저용 복구코드를 제공하지 않습니다. 전달받은 화면에서 직접 복사·저장해 주세요.

4. 청약철회·환불·미제공·중복 결제

디지털 콘텐츠 전문의 즉시 제공에 동의하고 실제 제공이 시작된 경우에는, 관련 법령에서 정한 고지·동의 등 요건을 충족한 범위에서 청약철회가 제한될 수 있습니다. 이는 모든 경우에 환불이 불가능하다는 뜻이 아닙니다. 법령상 보장되는 권리는 동의만으로 배제되지 않습니다.

결제했지만 콘텐츠가 제공되지 않은 경우, 동일 결과에 중복 결제된 경우, 금액·결제 처리 오류, 계약 내용과 다른 제공 등은 확인된 사업자 문의처로 요청해주세요. 주문 식별정보와 문제 상황을 알려주면 결제·제공 상태를 확인하여 관련 법령과 거래 조건에 따라 처리합니다. 추가 결제로 해결하려 하지 마세요.

‘내용 삭제’는 환불 신청 기능이 아닙니다. 환불이나 미제공 문제를 요청하려면 내용을 먼저 삭제하지 말고 문의해주세요. 문의에 카드번호·CVC·결제키·복구코드를 포함하지 마세요.

서버 제공 세부 환불 안내

5. 보관·만료·삭제

  • 재시도 캐시부분 미리보기·추가 확인 질문 등 재시도용 응답은 암호화해 최대 15분 보관하며, 삭제 요청 시 함께 정리합니다. 입력 원문 전체를 재시도 캐시에 넣지 않습니다.
  • 미결제 수정 결과심층 분석 보고서·수정문·변경 전후 발췌·검수 근거를 암호화해 생성 시점부터 최대 1시간 임시 보관합니다.
  • 결제 확인 중 / 아직 전달되지 않은 승인 결과결제 확인 시작부터 최대 24시간, 승인 결과는 승인 시각부터 최대 24시간 보호 보관합니다. 다시 열어도 이 기한이 연장되지는 않습니다. 보관 자체가 전문 열람 권한을 뜻하지 않습니다.
  • 전문 전달 후전문이 화면에 전달되면 서비스 DB의 임시 콘텐츠와 재시도 캐시 삭제를 요청합니다. 서버가 성공을 확인해야 삭제 완료로 표시합니다. 실패 시 미완료 안내·재시도 버튼이 표시되며 위 최대 기한이 적용됩니다. 전달 후 현재 화면에서는 복사·저장이 가능하지만, 새로고침·닫기 후 복구할 수 없습니다.
  • 결제·계약 기록주문 식별정보·금액·상태 등 최소 거래기록은 콘텐츠와 분리해 거래일로부터 5년(달력 기준) 보관합니다. 자기소개서 내용을 5년 보관한다는 뜻이 아닙니다. 미승인·미착수 주문은 별도 단기 기한을 적용합니다.

기존 v3 작성 상품으로 생성된 결과에는 기존 고지 기간(미결제 24시간, 승인 확인 대기 최대 7일, 승인일부터 7일)이 적용됩니다. 새 첨삭 상품의 삭제 정책을 기존 결과에 소급 적용하지 않습니다.

내용 삭제는 브라우저 입력을 비우고 서버의 결과·복구권한 삭제를 요청합니다. 보관 기한이 지난 결과는 만료되며, 삭제·만료된 콘텐츠는 다시 제공할 수 없습니다. 별도 보관하려면 전문을 전달받은 현재 화면에서 TXT 저장 등으로 내려받으세요.

콘텐츠 삭제와 결제 거래기록 보관은 별개이고, 삭제가 무료 한도 초기화나 자동 환불을 뜻하지 않습니다. 외부 AI 처리업체의 보유 조건은 개인정보처리방침에서 별도로 안내합니다.

관련 법령 확인

구체적인 권리·의무는 실제 거래와 적용 법령에 따라 판단됩니다. 아래는 이 안내와 관련된 공식 법령입니다.
