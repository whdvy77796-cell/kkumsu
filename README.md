# 인소서 · 인터뷰엔 자소서

미리 정리한 경험이 없어도 쉬운 질문에 답하며 쓸 내용을 찾고, 지원 목적·문항·채용공고에 맞는 자기소개서로 연결합니다. 일반 대학 신입학 자기소개서는 지원하지 않지만, 대학 경험은 취업 글의 소재로 사용할 수 있습니다.

## 작성과 검수

원본 30문항 질문은행을 바탕으로 한 번에 한 질문, 총 10~30개 질문을 진행합니다. 답변 → 사실과 AI 해석 구분 → 사용자 정정·소재 선택 → 근거 기반 초안 → 별도 검수 순서입니다. 문항 응답성·구체성·본인 기여·판단·직무 연결·중복·상투어·자연스러움의 8개 기준을 검사하고, 1회 보완 후 필수 문제가 남으면 결과를 공개하지 않습니다. 수치·제외 문구 검사는 보수적 휴리스틱과 AI 검수를 함께 사용하며 모든 의미상 변형·정확성·합격을 보장하지 않습니다.

## 상품과 접근 제어

무료 1회 부분 미리보기 → 3,000원 승인 확인 → 해당 결과 전문 열람·복사·TXT 저장. 구독, 자동 결제, 새 글 재생성 상품이 아닙니다. 무료 기록은 익명 브라우저 기준이며 삭제만으로 초기화되지 않습니다. 미결제 API에는 제한된 문장만 제공하며 전문·출처·검수 원문을 보내지 않습니다. 서버가 PG 상태를 확인해야 전문을 열고, 환불·부분취소 시 이후 서버 열람을 차단합니다. 이미 내려받은 파일을 회수할 수는 없습니다.

## 비용과 보관

기존 일일·누적 AI 비용 장부와 한도를 그대로 사용합니다. 신규 인터뷰 시작 전에 최소 작성 여력을 확인하고, 각 실제 호출은 원자적 비용 예약으로 별도 보호합니다. 시작 가능 표시는 전체 인터뷰 비용이나 동시 사용자 여력을 보장하지 않습니다. 자동 충전·추가 구매를 수행하지 않습니다.

미결제 결과 24시간, 첫 승인 확인 시작 후 처리 대기 최대 7일, 승인 결과는 실제 승인 시각부터 7일입니다. 읽기·재시도로 연장하지 않습니다. 재시도 캐시는 15분이며 최소 거래 장부는 콘텐츠와 분리해 5년 보관합니다. 개인정보·외부 AI 처리와 보유·삭제 범위는 public/privacy.html을 확인합니다.

## 실행·배포

Node 22. npm install 후 npm test로 전체 검사를 실행합니다. Vercel 정적 출력은 public/이며 API는 api/입니다. 배포 빌드도 npm test를 실행합니다. 비밀값은 환경변수로만 설정하고 .env.example에는 실제 값을 넣지 않습니다. 기존 꿈수 파일과 운영 커밋, 교체 전 ZIP 백업은 보존합니다.

/api/payment-reconcile은 인증된 GET 전용이며 Production 배포의 Vercel Cron이 10분마다 호출합니다. Preview에서는 예약 실행을 보장하지 않습니다. disabled 모드에서는 공급자를 부르지 않고 건너뜁니다. 실제 결제는 기본 disabled입니다. 계정·가맹점·사업자/정책·지원/환불 운영·백업·WAF/모니터링·건강한 재조정 작업을 실제로 확인하기 전에는 활성화하지 않습니다. 세부 조건은 PAYMENT_INTEGRATION.md를 참고합니다.

## 검증 근거와 한계

현재 전체 단위·모의 회귀 149개 통과 기록은 tests/last-run.txt에 있습니다. 실제 Upstash Redis에서 최신 11개 Lua export의 16개 묶음·619개 확인을 통과했고 격리 테스트 키 65개를 정리했습니다(QA_REDIS_LIVE.json). 이는 실제 PG 승인·다중 클라이언트 부하·장기 장애나 백업 복구를 증명하지 않습니다.

350자 제한의 실제 AI 검증은 초안·별도 검수 2회로 283자 결과를 반환했습니다(QA_V3_LIVE_RESULT.json, 최초 Preview d340922). 입력은 QA_LIVE_CASE.json이며 공식 채용공고와 가상 지원자 경험을 사용합니다. 이후 불필요한 자기부정·중복 보강질문 방지 지침을 추가했으나 추가 실호출은 하지 않았습니다. 실제 지원·합격 사례가 아닙니다. OpenRouter 화면의 이 2회 표시 비용 합계는 약 $0.0386이며 추가 충전·한도 변경은 하지 않았습니다(QA_V3_LIVE_COST.json). 500/700자 이전 버전 검증은 별도 구형 자료이며 이번 버전 결과로 취급하지 않습니다. 토스 일반 결제창의 계정 연계·실제 테스트 승인 왕복은 아직 확인되지 않았습니다.

## Preview 검증과 공개 전 정리

8ec4375 Preview에서 이전의 고정 가상 결과를 추가 모델 호출 0회·예약 비용 0원으로 재사용했습니다. 일반 결과 API와 화면 복구에서 전체 283자 중 69자만 전달되고, 전문·출처·검수 원문이 빠지며 복사·저장·결제가 잠긴 것을 확인했습니다(QA_PREVIEW_RUNTIME.json). 이 재사용은 후속 프롬프트의 실제 AI 품질 검증이 아닙니다.

운영용 소스에는 임시 QA API·함수 설정·예시 비밀값을 두지 않습니다. 저장소의 임시 API 파일 삭제, Preview QA 환경변수 제거, 이전 QA 배포 정리와 최종 404 확인을 마친 후에만 공개 전 검증이 끝난 것으로 봅니다. 현재 Production은 이전 버전이며 실제 결제는 계속 disabled입니다.

## 로컬 화면 검증

390px·360px 가상 데이터 file:// 화면에서 홈·문항 입력·사실 선택/정정·해석 제외·잠금 미리보기·정책 링크와 동의창의 키보드 순환/Escape/초점 복원/배경 inert를 확인했습니다. 실제 POST는 차단됩니다. 로컬 HTTP 접속은 환경 격리로 확인하지 못했으며 실기기·실제 PG 검증이 아닙니다. scripts/build-ui-qa.mjs의 ?qa=facts / ?qa=facts-corrected는 로컬 산출물에만 주입됩니다.

APP_ORIGIN은 Production의 https://www.kkumsu.com 과 Preview의 https://kkumsu-git-insosoe-v3-kkkkkum.vercel.app 로 분리합니다. 주소 설정 없이 결과 복구 API를 쓸 수는 없습니다. Preview 검사는 고정 브랜치 주소에서 수행하며, 임의 배포 주소 사이의 브라우저 식별은 자동 공유되지 않습니다.

제한된 Windows 샌드박스에서 테스트 파일 탐색이 막힐 경우 node --preserve-symlinks --preserve-symlinks-main scripts/run-local-tests.mjs 로 동일 테스트를 등록해 실행할 수 있습니다. CI는 npm test를 그대로 사용합니다.
