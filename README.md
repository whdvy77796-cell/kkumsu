# 인소서 · 자소서 심층 분석 Preview

## 2026-11-06 신규 화면과 범위
- 자소서 한 편을 붙여넣거나 TXT·PDF(텍스트층)·DOCX로 불러옵니다. HWPX는 시험 기능이며 구형 HWP·이미지 OCR은 지원하지 않습니다. 파일 원본은 브라우저에서 읽고, 추출한 글은 사용자가 동의하고 분석을 요청할 때 서비스 서버와 외부 AI로 전송합니다.
- 회사·직무·문항·글자수는 따로 입력받지 않습니다. 원문에 명시된 정보는 분석에 참고할 수 있지만, 문항 적합성과 글자수 상한 충족을 독립적으로 검증하지는 않습니다.
- simple-v3는 근거 문장을 바탕으로 심층 분석과 수정본을 만들고 별도 AI 호출로 대조합니다. 없는 경험·성과·수치를 만들지 않도록 검수하지만 모든 오류를 막지는 못하며 결과의 진실성·합격을 보증하지 않습니다. 유료 전문 결제는 여전히 준비 중입니다.
- 무료 응답은 수정본의 제한된 전후 발췌와 안전하게 공개 가능한 진단 일부만 전달합니다. 상세 분석과 전문은 무료 응답에 포함되지 않습니다. 과거 simple-v1/v2 결과와 기존 보관 조건은 유지합니다.
- 실제 사용 문서를 테스트·소스에 넣지 않습니다. 짧은 가상 자소서를 실제 AI로 시험했으며, 성공한 사례와 응답 형식 차단 사례가 모두 있어 다양한 글에 대한 안정성과 품질은 추가 검증이 필요합니다. 모의 시험과 실사용·현장 검증을 구분합니다.

# 인소서 · 자소서 간편 첨삭 Preview

첫 화면에서 자소서 1편을 붙여넣어 시작합니다. 지원 문항·직무·회사·공고·글자 수 제한은 선택입니다. 미입력한 문항/분량은 검토한 것처럼 표시하지 않습니다. 본문 40~6,000자, 일반 대학 입학 자소서는 제외합니다. 상세 상품·보안·호환 계약은 SIMPLE_PREVIEW_CONTRACT.md를 보세요.

## 상품과 검수
첫 익명 브라우저 1건의 분석·일부 미리보기는 무료이며, 해당 글의 전문·상세 변경 이유·복사·TXT는 3,000원입니다. 별도 수정과 검수를 기본 2회, 필요시 최대 4회 호출합니다. 없는 사실·수치 추가를 막도록 검수하지만 모든 의미상 변형, 사실의 진실성, 합격을 보장하지 않습니다. 무료 결과에는 검수 분류에 기반한 고정 설명과 실제 전후 발췌를 최대 세 쌍까지 제공합니다. 모든 전후 발췌 합계는 수정본 길이의 25% 이내이며, 남은 잠금 부분은 실 텍스트가 아닌 모형입니다. 변경이 없거나 발췌가 적절하지 않다면 전후 비교가 없을 수 있습니다.

## 보관·결제
새 결과는 미결제 최대1시간, 결제확인 대기 또는 미수신 승인 결과 최대24시간 암호화 임시보관합니다. 전문 수신 후 삭제 요청의 성공을 확인하고, 외부 AI·로그·백업은 별도 정책을 안내합니다. 이전 V3/V4 결과의 기존 조건과 예전 미리보기는 유지합니다. 실결제는 disabled입니다.

## 검증과 한계
로컬 Node 단위 및 모의 통합 테스트와 별도 모의 UI 검사입니다. 과거 132자 가상 자소서 한 편의 실제 AI 수정·검수와 제한된 미리보기는 확인했지만, 긴 글·다양한 문항의 품질이나 실 PG·실 기기·부하·재난복구·법률 검증을 뜻하지 않습니다. 교정 노트 화면 변경 자체는 추가 실 AI 호출 없이 모의 데이터와 기존 보관 결과로 확인합니다.

## Claude·삭제 안내와 동의 개편
현재 Preview 설정은 OpenRouter를 통해 Claude 모델을 사용합니다. 모델·중계업체는 서버 상태를 기준으로 표시하며, 실제 하위 처리업체·국외 처리 조건은 출시 전 확인이 필요합니다. 전문 표시 후 서비스 DB 콘텐츠·재시도 캐시 삭제 요청과 확인을 안내하고, 외부 AI·백업·로그·거래기록은 별개입니다. 새 화면에서는 AI 전송 동의만 체크하고 나머지는 신청 전 표시합니다. 결제 전 별도 법정 고지와 동의는 유지합니다.
