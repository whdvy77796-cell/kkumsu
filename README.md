# 인소서 · 인터뷰엔 자소서

취업·이직 등 지원에 필요한 경험을 한 번에 한 질문으로 정리하는 AI 인터뷰 서비스입니다. 대학 입학 자기소개서는 지원하지 않습니다. 대학에서의 경험 자체는 취업 글의 소재로 사용할 수 있습니다.

## 실제 처리 흐름

원본 30문항 질문은행 → 답변에 맞춘 실제 AI 후속 질문 → 말투·소재 선택 → 사용자가 사실과 해석 확인 → AI 초안 → 별도 AI 검수 및 필요 시 분량 재검수. 확인된 사실만 생성 입력으로 사용하며, 사실 오류나 합격 여부를 보장하지 않습니다.

## 운영 범위

- 첫 생성 1건만 무료. 익명 브라우저 식별자 기준이며 내용 삭제로 무료 기록이 초기화되지 않습니다.
- 기존 심화 2,000원 / 재작성 2,000원 / 재작성+심화 3,000원은 표시만 하고 결제 및 유료 생성은 차단합니다. 결제 연동 검증 전에는 판매하지 않습니다.
- 기본 제공자 OpenRouter, 모델 anthropic/claude-sonnet-5.5. 자동으로 다른 모델로 바꾸지 않습니다.
- 전용 Upstash Redis 필요. AI 키·세션·Redis 설정이 없으면 로컬 문장 조합을 제공하는 대신 기능을 차단합니다.
- 코드 기본 한도는 일 1 USD, 누적 2 USD이며 현재 초기 운영은 일 2 USD·누적 2 USD로 설정했습니다. 누적 한도는 자동 초기화하지 않습니다. 예상 최대 비용을 먼저 예약하고 성공한 모든 호출의 usage가 확인될 때만 보수적으로 정산합니다. 추가 충전이나 결제는 자동으로 수행하지 않습니다.
- 입력은 브라우저 메모리에만 유지합니다. 새로고침·닫기 전 TXT를 내려받아야 합니다. 재시도 결과만 서버에서 암호화해 최대 15분 보관하며 외부 AI 업체 정책과는 별개입니다.

## 실행 및 배포

Node 22, Vercel Git 배포. 정적 출력은 public/만 사용하고 /api/insosoe.js를 서버 함수로 처리합니다. OPENROUTER_API_KEY와 KV_REST_API_URL, KV_REST_API_TOKEN은 Vercel 비밀 환경변수로만 관리합니다. 별도 SESSION_SECRET 설정을 권장하며 미설정 시 제공자 키를 기반으로 세션을 보호합니다.

`npm test`는 실제 유료 API를 부르지 않는 서버 회귀 테스트입니다. 실제 AI 품질과 Redis 통합 시험은 별도로 진행해야 합니다.

## 교체와 복구

기존 꿈수는 교체 전 ZIP 백업과 Git 이력을 유지합니다. 이전 API는 410 응답으로 종료하며 이전 루트 파일은 새 정적 출력에 포함하지 않습니다. 복구 시 보존한 꿈수 커밋 또는 백업 ZIP을 사용하고, 배포 대상과 출력 경로를 함께 되돌립니다.
