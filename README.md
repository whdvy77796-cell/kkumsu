# 인소서 · 문항 맞춤 첨삭 V4

기존 인터뷰 중심 서비스를 기존 초안의 문항 맞춤 첨삭으로 전환했습니다. 1건은 지원 문항 1개입니다. 원문·문항·글자수 기준을 입력하고 문항 응답성, 논리/역할, 원문 근거/수치, 문장/맞춤법, 분량을 살핍니다. 일반 대학 입학 지원은 제외하며 대학 경험을 취업 글에 사용하는 것은 허용합니다.

## 품질과 비용
- 기본 수정 + 별도 검수 2회. 필수 문제가 있으면 보완 1회 + 재검수 1회, 요청당 최대4회입니다. 각 호출의 입력바이트·출력토큰 상한을 미리 예약하고 실행 때 같은 상한을 적용합니다.
- 필수 사실이 없을 때만 최대3개 추가 확인 질문, 한 차례 추가답변. 공개 질문은 서버 소유 템플릿으로 정규화해 질문 필드의 전문 유출을 막습니다. 추가 답변 요청도 같은 예산·쿼터 규칙을 적용합니다.
- 원문/추가답변 밖 수치와 단위, 발췌의 원문·수정문 일치, 검수 대상 해시, 필수 검수기준을 검사합니다. 의미상 역할·판단·인과 검사는 별도 AI 요청에 의존하며 모든 오류나 사실의 진실성·합격을 보장하지 않습니다.
- AI 일일·누적 비용과 IP/세션 쿼터, 동시 처리 잠금은 기존 v2 장부를 그대로 사용합니다. 첨삭 무료 이용권만 v4로 분리합니다. 추가 충전·한도 상향·자동 충전은 하지 않습니다.
- 요청에 OpenRouter data_collection deny 및 zdr true를 명시합니다. 계정별 Safety Retention·법적 예외·외부 업체 정책까지 무보관이라고 보장하는 설정은 아닙니다.

## 유료 잠금
첫 익명 브라우저 1문항의 일부(최대25%)만 무료 미리보기. 해당 수정 전문·변경 이유·복사·TXT는 기존금액 3,000원입니다. 구독/추가 재수정/새 글 생성 상품이 아닙니다. 서버가 PG DONE을 확인하기 전 전문·변경 내역·검수 원문·근거를 반환하지 않습니다. 실제 결제는 disabled를 유지합니다. 기존 가맹점·약관·환불/지원·대사 작업 조건은 별도 완료 전 활성화하지 않습니다.

## 데이터 삭제
- 원문을 독립된 원문 문서로 보관하지는 않지만 수정문·발췌·검수 근거에는 원문과 동일한 내용이 포함될 수 있으며 암호화 임시 보관합니다.
- 신규 미결제 결과는 생성 후1시간, 결제확인 대기는 시작 후24시간, 아직 수신하지 않은 승인 결과는 승인시각부터24시간입니다.
- 전문 수신/화면 표시 후 콘텐츠 DELETE 및 재시도캐시 DELETE를 실행하고 두 성공을 확인해야 삭제완료로 표시합니다. 이후 본문은 현재 화면 메모리에 남아 복사/다운로드할 수 있으나 새로고침/닫기 후 복구할 수 없습니다. 신규 첨삭 복구코드는 없습니다.
- 일반 지우기는 scope revision으로 미수신·진행중 V4 요청까지 취소/삭제합니다. SAVE_RESULT와 FINISH_REVISION 양쪽에서 취소표식을 검사합니다. scope cache는 특정 결과 삭제 후 정리 전용입니다.
- 최소 거래기록·무료이용·보안 기록은 분리 유지합니다. 앱 DB 삭제는 인프라로그/백업/외부AI의 모든 사본 완전삭제 인증이 아닙니다.
- 기존 V3 결과의 약속한 보관기간과 운영 꿈수/main은 그대로 보존합니다.

## 실행 및 현재 검증
Node22.x, npm test. Windows 제한환경에서는 node --preserve-symlinks --preserve-symlinks-main 으로 scripts/run-local-tests.mjs를 import해 실행할 수 있습니다.
현재 로컬 단위/모의 회귀 241/241 통과(기존149 + 신규92), tests/last-run-v4.txt. 실제 PG·실 Redis EVAL·부하·장애복구 보증은 아닙니다. V3의 QA_*.json과 기존 last-run.txt는 역사자료이며 V4 실모델 품질 검증으로 취급하지 않습니다.

로컬 UI 가상 테스트 빌더는 scripts/build-ui-v4-qa.mjs이며 배포 public에는 QA 우회나 모의승인 기능을 넣지 않습니다. file URL은 브라우저 로컬 접근 권한으로 차단되어 실제 UI는 Preview에서 검증합니다. 후속 실제 AI·Preview 검증은 별도 QA_V4 기록으로 남깁니다.
